# MotoRoute – version Android

Application du club de motards MotoRoute (français / arabe / anglais).

- `www/index.html` : l'application elle-même (la même que sur Netlify).
- À chaque mise à jour, GitHub fabrique automatiquement une application Android
  de test (`.apk`) : onglet **Releases** → dernière « MotoRoute – version de
  test » → toucher le fichier `.apk` pour l'installer sur le téléphone.

Étapes suivantes : tester l'APK, icône MotoRoute, version signée `.aab` pour Google Play.
